# Engineering foundation

SaafSky is built as a focused Next.js and TypeScript application with clear
boundaries between accessible UI, deterministic air-quality policy, external
providers, and optional AI explanations.

## Product foundation

The dashboard, daily planner, indoor advisor, commute impact calculator,
assistant, preferences, and scenario explorer share one validated city and
household context. Air-quality guidance is generated by testable domain rules;
Gemini explains those actions using structured, validated output.

The application supports English and Hindi, responsive mobile and desktop
layouts, browser-local preferences, cached provider requests, and a
fixture-backed testing workflow. Provider credentials stay server-side.

## Engineering practices

- Strict TypeScript and runtime validation at external boundaries.
- Typed AQI policies, recommendation identities, evidence references, and
  environmental-data schemas.
- Shared UI components for household controls and recommendation display.
- Isolated provider adapters with deterministic substitutes for automated tests.
- Focused accessible status updates, keyboard-operable controls, and
  responsive layouts.
- Central request budgets, provider timeouts, cache lifetimes, and release
  verification scripts.
