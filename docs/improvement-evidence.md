The latest source changes centralize server request and provider budgets,
validate Gemini model configuration, and inject the Gemini interaction client
so output validation, malformed responses, and model fallback can be tested
without network access. The assistant passes AQI and forecast data through an
explicit typed context, and its output validator rejects numeric digits in AI
prose even when those values appear in the supplied context. It also checks
context-paired spelled quantities and selected high-risk unsupported claims.
Exact readings remain visible in the deterministic dashboard and forecast UI.

## Security and accessibility backlog

- The enforced static-compatible CSP is covered by production browser tests.
  A stricter script policy remains a separate design decision because inline
  Next.js scripts and Cache Components affect nonce-based dynamic rendering.
- Retest keyboard and assistive-technology behavior after accessibility-related
  UI changes; the project owner reported successful hands-on checks on November
  26, 2026, including English/Hindi and dynamic content.
- Assistant output validation rejects numeric digits and context-paired
  English/Hindi number words. It also rejects targeted absolute-safety,
  efficacy, and unreferenced product/household claims. Free-form language still
  cannot be fully verified for every qualitative claim.
- A live local smoke now verifies the air, location, Gemini, and configured
  Redis-backed request paths. A separate live Upstash smoke passed 24 concurrent
  requests against a unique one-minute verification prefix and confirmed that
  another visitor receives a separate permit. This bounded test does not measure
  production traffic fairness or large-scale load.
- Continue parameterizing dynamic translation messages and extend the bounded
  Redis concurrency smoke if deployment topology or traffic patterns change.

The November 25 `npm audit --omit=dev --audit-level=high` run reported zero
known vulnerabilities in production dependencies. It does not assess the
application or undisclosed vulnerabilities.

No external certification, complete security assessment, or evaluation score
is implied by these checks.
